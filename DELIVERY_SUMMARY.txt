HOW TO RUN
================================================================================

TERMINAL 1 - Start Backend:
  cd backend
  pip install -r requirements.txt
  python -m uvicorn main:app --reload --port 8000

TERMINAL 2 - Start Frontend:
  npm install
  npm run dev

BROWSER:
  Frontend: http://localhost:5173
  Backend:  http://localhost:8000
  API Docs: http://localhost:8000/docs

================================================================================
SCORING SYSTEM
================================================================================

OVERALL FIT SCORE (0-100)
  40% Skills Match     - Does candidate have required skills?
  30% Experience Fit   - Did they work in similar roles?
  30% Evidence Quality - Do they have projects/certs/education?

ROLE-AWARE ANALYSIS
  - Uses job title for context
  - Generates role-specific interview questions
  - Compares against both title and description
  - Optional (works without it, but better with it)

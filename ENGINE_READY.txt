🎯 ARCHITECTURE OVERVIEW
════════════════════════════════════════════════════════════════════════════

User Upload CV + Job Description
              ↓
        FastAPI Server
              ↓
    ┌─────────────────────┐
    ↓         ↓           ↓
FileParser CVExtractor JobFitAnalyzer
    ↓         ↓           ↓
    └─────────────────────┘
              ↓
    JSON Response with:
    • Extracted CV data
    • Fit scores (3-part)
    • Strengths & gaps
    • Interview questions
              ↓
        React Frontend
    (Dashboard displays results)

🔧 CUSTOMIZATION HOOKS
════════════════════════════════════════════════════════════════════════════

Add Skills:
  Edit backend/cv_extractor.py:
  TECHNICAL_KEYWORDS = { 'python', 'javascript', ... }

Adjust Scoring:
  Edit backend/job_fit_analyzer.py:
  Change weight in analyze() method

Modify Fit Rules:
  Edit _calculate_skills_match(), _experience_fit(), etc.

Fine-tune Extraction:
  Regex patterns in cv_extractor.py can be customized
